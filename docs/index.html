01 / FROM SCRIPT TO SLIDES

Start in three steps

Linux x86-64 · Java 21 / 25

The packaged CLI needs no Node.js, Gradle, or Maven installation. Use JBang below, or download the standalone JAR.

1

Install the CLI

Check java -version and install JBang. Run these commands and follow the PATH setup instructions.

jbang app setup
jbang app install --java 21 --name revealkt dev.limebeck:revealkt-cli:1.1.1
Prefer a standalone JAR?

Download the self-contained CLI JAR from release 1.1.1, rather than the sources, javadoc, or app-jvm artifacts. Rename it to revealkt.jar if needed. In the commands below, replace revealkt with java -jar /path/to/revealkt.jar.

2

Create a presentation

The CLI creates a Demo directory with a script and assets. Open Demo/presentation/Demo.reveal.kts in your editor.

revealkt init Demo
3

Preview and make it yours

Start the server and open localhost:8080. Saving your script or assets updates the presentation.

revealkt run Demo/presentation/Demo.reveal.kts --host 127.0.0.1 --port 8080

03 / YOUR DAILY WORKFLOW

From first draft to final talk

Replace Talk.reveal.kts below with the path to your script.

01 · CHECK

Ready to go?

Check Java, paths, output access, and a real Chromium launch. The script is not executed.

revealkt doctor Talk.reveal.kts
02 · PREVIEW

Edit with live reload

Run a local preview. If an edit fails, the last working presentation stays available.

revealkt run Talk.reveal.kts --host 127.0.0.1
03 · HTML

Share a link

Publish the entire out directory to a static host, including its JavaScript, CSS, and assets.

revealkt bundle Talk.reveal.kts --output-dir out
04 · PDF

Take it with you

Install Chromium first. A separate port lets you keep the preview server running.

revealkt chrome install
revealkt pdf Talk.reveal.kts --port 8081 -o Talk.pdf
04 / MAKE IT YOURS

Your slides. Your style.

Themes and slide numbers

Choose a built-in theme and numbering format. Combine all fragment steps on one slide page in PDF.

configuration {
    theme = RevealKt.Configuration.Theme.Predefined.BLACK
    slideNumber = RevealKt.Configuration.SlideNumber.Custom("c/t")
    pdfSeparateFragments = false
}

Add import dev.limebeck.revealkt.core.RevealKt. Use additionalCssStyle for small CSS overrides.

Keep assets beside your script

Place images and CSS in assets/. The image DSL adds this prefix for you.

presentation/
├── Talk.reveal.kts
└── assets/
    ├── logo.svg
    └── theme.css
// Inside regularSlide
+img(src = "logo.svg") { width = 320 }
How do I use a custom CSS theme?

Set theme = RevealKt.Configuration.Theme.Custom("assets/theme.css") inside configuration. A custom theme replaces the built-in theme; style .reveal-viewport, .reveal, and headings. URLs inside CSS resolve relative to the CSS file. Start with a complete template: revealkt init ThemeStudio --example custom-theme.

How do incremental list items work?

unorderedListOf and orderedListOf reveal subsequent items as fragments by default. The first item is visible immediately. Pass fragmented = false for a static list. Set pdfSeparateFragments = false to avoid extra PDF pages for fragment steps.

05 / WHEN SOMETHING GOES WRONG

A few quick answers

My edit produced an error. What happens now?

Fix the script and save again. Successful compilation updates the slides and removes the error panel. Until then, you can navigate the last working presentation. An error on the initial launch exits the command; fix the script and start it again.

PDF export fails or Chromium will not start

Run revealkt chrome install, then revealkt doctor Talk.reveal.kts. On Ubuntu, you may need system libraries: revealkt chrome install --with-deps. If the port is busy, stop the preview or use --port 8081. Create the PDF output's parent directory beforehand.

Why is my image missing?

Check that assets/ is beside your script. For assets/images/chart.png, use img(src = "images/chart.png"). Paths are case-sensitive. CSS theme URLs need the full assets/ prefix.

Do exported slides work offline?

Built-in JavaScript and CSS ship with the CLI. External images, fonts, and MathJax may still need a network connection, so offline export is not guaranteed. HTML export is a directory, not one file. Repeating bundle does not remove old assets; use a fresh output directory for a clean export.

Can I run someone else's presentation?

A .reveal.kts file is executable Kotlin with your user's permissions, including file and network access. Review scripts before running them. Preview has no authentication; --host 127.0.0.1 limits access to your computer. Use bundle for publishing.
